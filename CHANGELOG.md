# Support routing 0.3.0 draft

Expanded the separate 32-case review draft to 500 cases across 91 families. Added 78 scenario briefs and six deterministic variants per brief, with 390 explicit base/variant links. The original 32 inputs and reference answers are preserved.

Added queue, priority, escalation, family, slice and counterfactual diagnostics, including an explicit relative priority-loss matrix. Strict output validity and full missing-answer denominators prevent malformed or absent results from appearing successful. The model response remains the same three fields.

Created 400 development and 100 visible evaluation cases with no family crossing the boundary. Recorded inherited split names in provenance. Added exact counts, lexical-overlap checks, generation/source hashes and a human-review worksheet.

Clarified that routine membership/access administration uses Account Access while security-purpose access guidance uses Security when there is no active blockage. This is a new proposed policy version; earlier policies and study results remain unchanged.

Added standalone offline scoring and CSV/JSONL exports, partition scoring and development-only Orlo comparison templates. The 0.3.0 template contains no release test. The original publication candidate remains 0.1.0 and does not acquire these new cases or imply that they were evaluated.

The repository owner authorized publication as an unreviewed research draft. The publication metadata and artifact hash now reflect that permission; the 500 case inputs and labels remain unchanged. No model comparison, independent label review or reuse license grant is included.
